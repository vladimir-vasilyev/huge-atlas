# План реализации

Каждый этап заканчивается работающей программой, которую можно проверить глазами.
Этапы 6–8 сначала отлаживаются на синтетических дисках, без VSA.

## Структура

```
src/core/     MeshTypes, MeshPrep, Proxy, Metrics, Partition, Operations
src/param/    PatchExtractor, PatchTopology, LinABF, AnglesToUV, Injectivity,
              Distortion, AtlasPacker, ParamPipeline
src/render/   шейдеры, буферы, камера, пикинг
src/ui/       панели ImGui
tests/
```

## Этап 0. Каркас — готово (нужна проверка сборки)

## Этап 1. Загрузка и отображение меша

- Подключить OpenMesh (статическая сборка) и Eigen в CMake.
- `TriMesh` с double-точностью (свои traits). Загрузка OBJ/OFF/PLY/STL через `IO::read_mesh`.
- Нормализация в единичный bounding box. Площади, нормали, центроиды граней — в массивы по `face.idx()`.
- Диагностика: вырожденные грани, неманифолдность, число компонент связности → панель статистики.
- VBO с развёрнутыми вершинами (3 на грань): плоское затенение и цвет на грань.
- Каркас через барицентрические координаты во фрагментном шейдере.
- Камера-arcball; мышь в сцену только если `!io.WantCaptureMouse`.
- Выбор файла: текстовое поле ImGui или `NSOpenPanel` (.mm).

## Этап 2. Метрики и фиттинг прокси

- L²,¹: ошибка треугольника |T|·‖n_T − N‖²; N = normalize(Σ|T|n_T); X = центроид по площади.
- L²: ошибка по формуле (3) статьи; ковариация через точный второй момент (см. CLAUDE.md);
  нормаль — собственный вектор наименьшего собственного значения.
- Тесты: сверка с численным интегрированием (разбиение треугольника на 4ⁿ).

## Этап 3. Разбиение затоплением (VSA 3.3)

- Первый засев — k случайных граней; далее — грань с минимальной ошибкой в каждой области.
- Min-heap `{ошибка, грань, прокси}`, ленивое удаление (грань до 3 раз в очереди).
- Компоненты без засева: дозасев. Ограничение k ≤ числа граней.
- UI: раскраска областей, кнопка «шаг». Проверка: рис. 7 (полусфера на плоскости).

## Этап 4. Итерации Ллойда

- Цикл разбиение → фиттинг, энергия E(R,P) после каждой итерации, график `PlotLines`.
- Остановка: max итераций или малое относительное изменение за несколько итераций.
- Метрика по умолчанию L²,¹. Отрисовка прокси эллипсами (опционально).
- Проверка: куб, k=6, L²,¹ → 6 граней, ошибка 0.

## Этап 5. Улучшения VSA 3.5

- Накопленные суммы по областям (площадь, Σ|T|n_T, моменты) → пробное слияние за O(1).
- Вставка прокси (худший треугольник худшей области), удаление (лучшая пара соседей),
  телепортация (порог: ошибка удаления < 1/2 ошибки худшей области).
- Farthest-point инициализация, покраска весов кистью (пикинг ID-буфером).
- Сглаживание нормалей — пропустить.

## Этап 6. Извлечение патчей

- Каждая область → отдельный `TriMesh` + отображение локальных вершин/граней в глобальные.
  Граничные вершины дублируются (швы).
- Проверка на диск: связность, χ = V − E + F = 1, одна граничная петля.
- Кольцо (несколько петель): разрез кратчайшим путём от внутренних петель к внешней.
- Ручка внутри патча: разбить область (этап 10).
- «Бабочка» (область касается себя в вершине): размножить вершину по веерам до вырезания.
- Слить/отбросить патчи из 1–2 треугольников.

## Этап 7. LinABF

- Переменные: углы, индекс через полуребро (угол при to_vertex внутри грани).
- Начальное приближение: исходные углы; при угловом дефекте > 1 рад у внутренней вершины —
  масштабировать веер на 2π/Σα. Зажать в [ε, π−ε].
- Строки A: треугольник (nₜ), вершина (nᵢ), линеаризованное колесо (nᵢ):
  Σ cot βᵢ·e_βᵢ − cot γᵢ·e_γᵢ = Σ log sin γᵢ − log sin βᵢ,
  для грани (v, v₊, v₋): β — угол при v₊, γ — при v₋. Обход через `vih_iter`.
- C = A·diag(α); (C·Cᵀ)x = b через `SimplicialLDLT`; e = D·Cᵀ·x; α* = α + e.
- Проверка невязок исходных нелинейных условий (1)–(3) и углов в (0, π).
- Не SPD → зависимые ограничения → ошибка извлечения патча (диагностика).
- Тесты: плоский патч (e≈0), кусок цилиндра/конуса, пример рис. 4:
  p1=(3,0,1), p2=(1,1,0), p3=(0,0,0), p4=(1,−1,0); T=(p1,p2,p3),(p1,p3,p4),(p1,p4,p2).

## Этап 8. Восстановление UV из углов

- МНК из ABF++: p₃ − p₁ = (sin α₂ / sin α₃)·R(α₁)·(p₂ − p₁), 2 уравнения на треугольник.
- Фиксация двух далёких граничных вершин. Нормальные уравнения + `SimplicialLDLT`.
- В каждом треугольнике циклическая перестановка: наибольший синус — в знаменателе.
- Жадная сборка обходом в глубину — как отладочный инструмент.

## Этап 9. Инъективность, искажение, атлас

### Обнаружение (модуль Injectivity)
Теорема: локально инъективное отображение диска с простой граничной кривой инъективно глобально.
1. Локально, до UV: все углы в (0, π); суммы углов граничных вершин ≤ 2π − δ.
2. Локально, после UV: знак ориентированной площади каждого треугольника.
3. Граница: самопересечение граничных петель через равномерную сетку, соседние рёбра пропускать.
   Точные предикаты Шевчука (`orient2d`).
Результат — список (перевёрнутые треугольники, складки у граничных вершин, пары пересекающихся
рёбер), подсветка в UV и в 3D.

### Исправление без дробления (по возрастанию стоимости)
1. Active set в LinABF: зафиксировать вышедшие углы и суммы у граничных вершин строками-равенствами,
   перерешать (≤ 2–3 итерации). Лечит перевороты и складки, глобальное перекрытие — нет.
2. Надрез от вершины с большим угловым дефектом до границы (кратчайший путь,
   веса рёбер по двугранному углу), перезапуск LinABF.
3. Tutte (граница на окружности) → SLIM + scaffold (SCAF, libigl). Принять, если искажение
   выросло не больше заданного коэффициента относительно LinABF.

### Искажение и упаковка
- Угловое искажение, отношение площадей, L²-stretch по Сандеру; цветом на 3D.
- Масштаб: площадь UV = площадь 3D. Поворот к минимальному bbox (калиперы).
- Shelf packing с гаттером, нормировка в [0,1]². Экспорт OBJ с `vt` (halfedge texcoords).

## Этап 10. Цикл доразбиения

- Брак: не диск / перевороты / пересечение границы после исправлений / искажение > порога.
- Прицельное разбиение: локальный VSA с k=2 внутри области, засевы — по треугольнику
  в каждой из двух перекрывающихся частей (рядом с пересекающимися рёбрами);
  Ллойд ограничен гранями области. Альтернатива — кратчайший путь между точками границы.
- Не трогать соседние патчи. Лимиты: глубина рекурсии, минимальный размер патча.
- Политика в UI: «сначала исправлять» / «сразу разбивать». Статистика веток по патчам.

## Тестовые модели

- Синтетика: куб, цилиндр, сфера, полусфера на плоскости.
- Перекрытия: полоса, навитая на узкий конус в 1.5–2 оборота; «волнистый веер» с суммой углов ~3π
  у граничной вершины; тонкие тупые треугольники у вершины большой кривизны.
- Классика: bunny, armadillo (Stanford), fandisk (тестовые данные libigl/CGAL), Max Planck.

## UI (итог)

Панели: Info, Mesh, VSA (метрика, k, шаги, энергия), Patches (статистика выбранного патча),
UV View (FBO → `ImGui::Image`), Settings (пороги). Режимы 3D: заливка, каркас, регионы,
шахматка по UV, искажение, швы.
