# Нативный интерфейс: правила HIG и что из них следует для huge-atlas

Источник: Apple Human Interface Guidelines в пересказах
[platform-design-skills](https://github.com/ehmo/platform-design-skills) (раздел macOS, правила с примерами AppKit) и
[apple-hig-skills / HIG Doctor](https://github.com/raintree-technology/apple-hig-skills) (ссылочный индекс страниц HIG: windows, sidebars,
toolbars, buttons, sliders, progress indicators, settings, file management, split views). Канонический текст — на developer.apple.com/design.
Правила ниже — то, что мы приняли обязательными для прототипа `huge_atlas_native` и для следующих этапов.

## Что принято

**Меню (критично).** Полная строка меню: App (About, Settings… ⌘,, Services, Hide ⌘H, Hide Others ⌥⌘H, Show All, Quit ⌘Q), File, Edit, View,
Window, Help. У каждого пункта-действия есть сочетание клавиш (⌘O, ⌘S, ⇧⌘S, ⌘W, ⌘0). Каждая кнопка панели инструментов дублируется
командой меню. Пункты включаются и выключаются по состоянию (`validateMenuItem:`), переключатели с галочкой. Названия и места команд
стабильны.

**Окна.** Свободно меняют размер, есть разумный минимум, полноэкранный режим (⌃⌘F), положение и размер запоминаются
(`setFrameAutosaveName`), светофор не прячем и не двигаем, заголовок окна — имя файла (`representedURL`), а не имя приложения.
Никакого своего оформления окна.

**Панель инструментов.** Единая с заголовком (`toolbarStyle = unified`): слева кнопка боковой панели, в центре частые команды и
переключатель видов (сегментированный контроль), справа главное действие. Иконки SF Symbols с подписями, без цветных фонов;
главное действие — ярким (prominent) стилем.

**Боковая панель.** Слева, сворачивается (кнопка и ⌃⌘S), прозрачность и вибрация системные (`NSVisualEffectView`, материал sidebar),
не больше двух уровней. Ничего критичного и никаких действий внизу боковой панели. В нашем случае это форма настроек шага за шагом;
виды (Patches / Presentation / Texture / UV checker) — в панели инструментов, не в боковой панели.

**Кнопки и контролы.** Компактные (высота 22–28 pt), без «пальцевых» размеров. Главная кнопка — по умолчанию (Return, системный
акцентный цвет); стиль, а не размер, выделяет предпочтительное действие. Кнопка, открывающая окно или панель, заканчивается
многоточием («Open…», «Save As…»). Ползунок подписан, показывает значение сразу, у дискретного — деления. Выпадающие списки (pop-up),
флажки и ползунки — системные.

**Индикатор прогресса.** Определённый, когда можно оценить долю; на месте, где пользователь его ждёт; с возможностью отмены
(⌘.) и подписью, что происходит. Для фоновых операций — маленький спиннер без подписи.

**Настройки.** Окно Settings (⌘,) только для общих, редко меняемых вещей (качество по умолчанию, режим разработчика, размер текстуры
по умолчанию); то, что меняют для каждой задачи, — в самом окне. Запоминается последняя вкладка.

**Файлы.** Открытие и сохранение — системные панели; перетаскивание файла на окно и на значок в Dock; сохранённая работа
никогда не теряется молча; без модальных предупреждений об удачных действиях (статус — рядом с кнопкой).

**Цвет и вид.** Системный шрифт (SF), семантические цвета, системный акцентный цвет (не фиксированный синий), светлая и тёмная темы,
уважение «Уменьшить прозрачность», «Уменьшить движение», «Увеличить контрастность», «Жирный шрифт». Отступы 20 pt по краям, 8 pt
между связанными контролами, 20 pt между группами.

**Доступность.** Все контролы доступны с клавиатуры (Tab, стрелки, Return, Esc), у не-текстовых элементов — метки для VoiceOver.
Сцена получает описание («3D-вид меша, N патчей»). ImGui этого не умеет — второй довод за нативные контролы.

**Указатель.** Подсветка при наведении, контекстное меню по правой кнопке на сцене (сбросить камеру, виды), drag-and-drop файлов.

## Что исправить в нынешнем интерфейсе на ImGui (по итогам чтения)

1. Нет меню Edit, Window (есть от GLFW), Help и пункта Settings ⌘, ; у действий («Make atlas», «Repack», «Compare») нет пунктов
   меню и сочетаний; «Developer Mode» в View лучше перенести в Settings.
2. Кнопки по 40 px и синяя «Make atlas» на всю ширину — «пальцевые» размеры; фиксированный синий вместо системного акцента.
3. Тёмная тема жёстко зашита, светлой нет; нет учёта Reduce Transparency / Motion / Contrast / Bold.
4. Нет VoiceOver, нет навигации по Tab, нет подсветки фокуса.
5. Нет контекстного меню на сцене, нет запоминания положения окна (кроме раскладки ImGui), заголовок окна — «huge-atlas», а не имя файла.
6. Статус и прогресс — текстом в боковой панели; нет определённого индикатора в одном и том же месте и отмены по ⌘. .

Прототип `huge_atlas_native` строится так, чтобы эти пункты закрывались сразу.
